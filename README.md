# eth-adam
Project repository for the SSBC course, created by Alessandro Stella, Gabriele Vianello, Serena Stefano, and Nicola De Cinque

The iStar model directory contains files to be imported into the piStar tool for working on the models to be analyzed. It is recommended to rename each file to indicate the model type and the author's name, in order to facilitate the final merging process.

The 'latex' directory contains the template to be used for project documentation. It is not a final version, so you are free to work on it, make modifications, or alter the template as needed. Submitting project documentation in Word format will result in your expulsion from the Order of Engineers.
